Who is shaping this law?

Per-dossier insight into interest representation around EU legislation.
All fourteen dossiers below link to a dedicated page with the same structure: documented lobbying pressure, interest representatives, a timeline, negotiators, an indicative lobbying-budget order of magnitude, and what has been achieved so far. Each page notes its own data gaps rather than filling them in.
